حزم الصور التلقائية
====================

أنشئ مجلدًا جديدًا داخل assets/packs/ وضع فيه خمس صور بأسماء ثابتة:

  assets/packs/اسم-الحزمة/thumb.png
  assets/packs/اسم-الحزمة/index.png
  assets/packs/اسم-الحزمة/middle.png
  assets/packs/اسم-الحزمة/ring.png
  assets/packs/اسم-الحزمة/pinky.png

الصيغ المدعومة: PNG وJPG وJPEG وWebP وBMP.
يمكن استخدام امتدادات بأحرف كبيرة أو صغيرة.

اختياريًا، أضف ملف pack.json لتحديد اسم عربي للحزمة:

  {
    "name": "ميمز 3"
  }

بعد حفظ الملفات، اضغط R داخل التطبيق أو أعد تشغيله.
ستظهر الحزمة الجديدة تلقائيًا مع بقية الحزم، ويمكن الوصول إليها
بمفتاح T أو بالأرقام 1-9.

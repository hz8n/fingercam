- الحزمة 1 (ميمز 1): thumb.png, index.png, middle.png, ring.png, pinky.png
- الحزمة 2 (ميمز 2): memes2/thumb.png ... memes2/pinky.png

يمكنك استبدال أي صورة بأي ميم آخر (PNG أو JPG)، ثم تعديل config.json:

   "stickers": {
     "thumb": "assets/meme.png"
   }

واضغط R داخل التطبيق.
يفضّل صورة مربعة تقريبًا. الصيغ المدعومة: PNG, JPG, JPEG, WebP, BMP, GIF.
